# Deep Reinforcement Learning

Deep reinforcement learning algorithms — DQN family, policy gradient methods (TRPO, PPO), actor-critic methods (DDPG, TD3, SAC), and model-based deep RL.

Classical methods live in [`Reinforcement-Learning`](https://github.com/SaiSampathKedari/Reinforcement-Learning). Theoretical foundations live in [`Sequential-Decision-Making`](https://github.com/SaiSampathKedari/Sequential-Decision-Making).
